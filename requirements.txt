# Why scipy is pinned
# ------------------
# scipy 1.15.3 is the last release supporting Python 3.10, and the only window in
# which BOTH the old `sph_harm` and its replacement `sph_harm_y` exist -- which is
# what allowed the spherical-harmonic migration to be checked numerically rather
# than guessed. The code now calls `sph_harm_y`, so newer scipy should work, but
# it has not been verified. See issues/015-scipy-sph-harm-pin.md.
