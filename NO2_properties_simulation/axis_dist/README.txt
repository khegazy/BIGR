Attached is a bunch of NO2 numerical data for different temperatures. It’s the time dependent ADMs (not <D^K_QS>) in a list, and a list of times in picoseconds for each calculation. The files are named by intensity, pulse duration and KS (so the D22 file is the ADM A^2_02). The <D^K_QS> and ADMs are analytically related as follows:

 

A^K_QS = ( (2K + 1)/(8*pi^2) )* <D^K_QS>

I think it might be better to write to your final expression for UED in terms of the ADMs, since these have a nice physical interpretation. But it’s up to you.
